# 期货盯盘工作台 · 需求文档（v1.0）

> 状态：方向已确认 · 定稿：2026-10-20 · 基于已验证能力：TqSdk 3.10.3 + 快期账户行情链路已跑通
>
> **已拍板的四个方向**：本地网页工作台 · 首批 3–5 个主力品种 · v1 纯行情不接账户 · 页面高亮+声音提醒

## 1. 背景与目标

当前盯盘方式是"盘中每 10–30 分钟让 AI 拉一次数据、出一次分析"，存在三个问题：

1. **不连续**：两次查看之间可能错过关键价位触达
2. **重复劳动**：每次都要重新拉数据、重算指标、重新叙述
3. **信号散落**：价位、指标、资金数据分散，缺少一张"当前该干什么"的决策面板

**目标**：做一个常驻运行的本地网页盯盘工作台，行情持续监控、指标自动计算、关键信号主动提醒，打开就能看到"现在该关注什么"。

**明确边界**：v1 只做行情监控与提醒，**不接任何账户、不做下单**（交易在用户自己的期货软件执行）。

## 2. 使用场景

| 场景 | 描述 |
|---|---|
| 盘中常驻 | 交易时段浏览器挂着，实时刷新行情与指标 |
| 价位盯守 | 预设支撑/压力/止损线，触达即提醒（不用一直盯着） |
| 盘后复盘 | 收盘后自动落盘当日行情快照，供复盘调用 |
| 非交易时段 | 显示最近收盘数据与状态提示，不报错不空转 |

## 3. 功能需求

### 3.1 P0 —— 核心盯盘（v1 范围）

| 编号 | 功能 | 说明 |
|---|---|---|
| F01 | 多合约行情面板 | 3–5 个主力品种（默认自选，可配置），**秒级驱动**（交易所 tick 逐笔驱动，非定时轮询）：最新价、涨跌、涨跌幅、成交量、持仓量、买卖一档，红涨绿跌；每次 tick 到达即推送页面，最高刷新频率受交易所快照频率限制（上期所约 0.5 秒/笔） |
| F02 | 实时 K 线图 | 选中合约的 1 分钟 / 5 分钟 / 日线切换；主连与具体月份合约可切换；**当前柱随 tick 秒级生长**，未完成柱明确标识（虚线边框或角标） |
| F03 | 技术指标 | MA(5/10/20)、BOLL 叠加主图；MACD、KDJ、RSI 副图切换——沿用既有多指标决策习惯；指标随 tick **增量重算**，仅当前柱实时变化，已完成柱锁定 |
| F04 | 关键价位监控 | 每个合约可设多条价位线（支撑/压力/止损），**逐笔 tick 检测**，触达即时（≤1 秒）高亮+声音提醒；提醒文案含情景提示（"破位"或"企稳"方向判断） |
| F05 | 指标信号提醒 | KDJ 金叉死叉、MACD 金叉死叉、价格触及 BOLL 上下轨、放量（量比阈值）自动检测并提醒，按**柱级**触发（避免 tick 级重复报警） |
| F06 | 连续运行与重连 | 断线自动重连（指数退避）；休市时段自动降级为静态展示，不阻塞不报错 |
| F07 | 页面通知 | 信号触发时：页面高亮条 + 声音 + 浏览器系统通知（Notification API），点击可跳转对应合约 |

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 时区 | 所有时间显示北京时间（UTC+8）；TqSdk 时间戳按 UTC epoch 转换（已实测验证，裸转差 8 小时） |
| 凭据安全 | 快期账户走环境变量/本地配置文件，不写进代码、不打印日志 |
| 数据准确性 | 未完成柱必须标识或剔除；模拟数据一律不得冒充真实行情 |
| 稳定性 | `wait_update` 一律带 deadline（休市会永久阻塞，已踩坑）；断线重连有退避；`api.close()` 保证释放 |
| 性能 | **秒级更新**：行情由 tick 驱动（交易所快照频率，上期所约 0.5s/笔），tick 到达 → 页面呈现端到端 ≤1 秒；价位触达检测逐笔进行；指标增量重算；多合约并行订阅控制连接数；后端→前端 WebSocket 推送，前端不做轮询 |
| 数据源 | 免费行情 API 为快期免费通道，存在轻微延迟（秒级）；如后续要求更低延迟，可评估专业行情授权（P2 备选，暂不做） |
| 合规 | 仅监控提醒，不做自动交易；下单永远在用户自己的期货软件完成 |

## 5. 技术方案

```
浏览器（ECharts 蜡烛图+指标线，红涨绿跌）
   ↑ WebSocket 秒级推送（tick 驱动，非轮询）
Python 后端（TqSdk 行情会话 wait_update 主循环 + tick 事件分发 + 指标增量计算 + 告警规则引擎）
   ↑ 交易所 tick/快照（上期所约 0.5 秒/笔，经快期通道）
上期所/大商所/郑商所
```

- **后端**：Python + TqSdk，单进程多合约订阅；SQLite/CSV 缓存 K 线与告警记录
- **前端**：本地 Web 页面（localhost），ECharts 画 K 线与指标，纯本地运行
- **配置**：`config.yaml` 管合约列表、价位线、指标参数、声音开关
- **已验证代码资产**：`fetch_klines.py` 的时区转换与未完成柱剔除逻辑直接复用

## 6. 里程碑

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| M1 | 多合约行情面板 + 单合约 K 线 | 3–5 品种 **tick 驱动秒级刷新**；1m/5m/日 K 切换正常；当前柱随 tick 生长；休市不报错 |
| M2 | 指标齐全 + 价位线提醒 | MA/BOLL/MACD/KDJ/RSI 显示正确；**逐笔**价位触达端到端 ≤1 秒提醒 |
| M3 | 指标信号 + 通知打磨 | 金叉死叉/BOLL 触轨/放量提醒准确率抽查通过；声音+系统通知可用 |
| M4 | 盘后复盘 + 配置化 | 收盘自动落盘快照；改配置文件即可增删合约与价位线 |
