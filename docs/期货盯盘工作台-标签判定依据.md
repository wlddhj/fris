# 期货盯盘工作台 · 标签判定依据

> 对应版本：2026-10-21（`workbench/static/index.html`）
> 目的：卡片上每个标签只有四五个字，凭什么是这个结论、下一步干什么，必须能当场查清。
> 本文是标签的「说明书」，页面上每个标签悬停显示的说明与本文一一对应。
> **看不懂某个词先跳到最后 §10 名词对照表**，那里用大白话解释了多突破位、空破位、滞涨区、基差、四象限等全部术语。

## 0. 先分清楚：四组标签回答的是四个不同问题

卡片头部一行三个标签，从左到右是「方向 → 时机 → 位置」；再加下方持仓建议块的方向词，一共四组。混着看必错。

| 标签组 | 位置 | 回答的问题 | 数据来源 | 刷新频率 |
|---|---|---|---|---|
| **方向倾向** | 第 1 个，如「方向：偏空 −2.5」 | 现在盘面**偏哪边** | MA5/MA20 排列 + 20日区间位置 + 四象限 + 资金失衡，四块打分合成（`dynDir()`） | 每 tick 重算 |
| **信号** | 第 2、3 个，如「⚪ 已破位·等反抽」 | **现在**能不能动手 | 当前周期 K 线收盘 + 关键位 | 每 tick 重算 |
| **持仓状态** | 第 4 个，如「持有区间内」 | 手上的单子**处于什么位置** | `advice.shortStop / swingStop / swingTarget` + 现价 | 每 tick 重算 |
| **持仓方向词** | 持仓建议块标题，如「持仓建议 · 持空待验」 | 手上这笔单**该用什么姿势拿** | 现价 vs MA5 + 当日四象限/资金是否反向（`advDir()` + `fundAgainst()`） | 每 tick 重算 |

一句话记法：**方向是「盘面偏哪边」，信号是「能不能做」，持仓状态是「做到哪了」，方向词是「这笔单还能不能理直气壮地拿」。**

### 0.1 颜色语义（全站统一三色）

**正面 / 多头 / 利多 = 红，中性 / 观望 / 平水 = 黄，负面 / 空头 / 利空 = 绿。** 与国内盘面「涨红跌绿」同一套：红=往上、绿=往下、黄=方向不明。

| 颜色 | 适用标签 | 例 |
|---|---|---|
| 红 | 强多 / 偏多 / 多头进攻（含弱多·浅红）/ 多头净流入 / 基差贴水（正基差，托底）/ 目标到达 / 分位高位 | 「方向：偏多」「多头进攻·强多」「✓ 自动触发」（利多信号） |
| 淡红 | **中性偏多**：方向总分落在 0 ~ +2 之间（结论仍是中性，只是符号偏多） | 「方向：中性 +1」（淡红）、弱多档 |
| 黄 | 中性（总分正好 0）/ 观望 / 无量整理 / 持有区间内 / 数据不足（待定） | 「方向：中性 0」「持有区间内」「无量整理·观望」 |
| 淡绿 | **中性偏空**：方向总分落在 −2 ~ 0 之间（结论仍是中性，只是符号偏空） | 「方向：中性 −1」（淡绿） |
| 绿 | 强空 / 偏空 / 空头进攻 / 多头离场（弱空）/ 空头净流入 / 基差升水（负基差，压制）/ 止损已破（价格走反）/ 分位低位 / 库存·出栏等「增=利空」数据 | 「方向：偏空」「🟢 空头破位触发」「库存 +0.52（累库，绿）」 |

> **为什么中性还要分淡红/淡绿**：方向标签的颜色按**总分符号连续过渡**，不是按结论词三档切。总分 +1 时结论确实是「中性」（不到 ±2 不动手），但它和 0 分不是一回事——0 分是多空证据互相抵消，+1 是已经偏多了。全给黄色等于把这层信息吃掉，所以：
>
> `≥+2 红` → `0~+2 淡红（中性偏多）` → `0 黄` → `−2~0 淡绿（中性偏空）` → `≤−2 绿`
>
> 颜色只表示「偏哪边」，**不代表可以下手**；能不能做看信号标签（第 3 节）。

两个例外，**不是**多空语义：风险告警（面板异动红框、数据异常红字、删除按钮）保持红——那是「危险/可操作」提示；人工确认的产业信号保持紫——那是「人工标记过」，不是方向。价位阶梯按空间上色：在现价**上方**=红、**下方**=绿（空单止损在上方是红、目标在下方是绿，多单镜像）。

> 2026-10-21 起，`playbook.json` 里人工设定的 `direction` 字段已废弃删除，方向全部由盘面数据实时推导。

## 1. 通用参数（全站共用，改这里就改全部标签）

| 参数 | 默认值 | 含义 | 配置位置 |
|---|---|---|---|
| `confirmBars` | 3 根 | 连续多少根 K 线收盘满足条件才算「确认」 | `playbook.json` → `confirmBars` |
| `nearPct` | 1.0% | 距关键位多近算「接近」（提前预警） | `playbook.json` → `nearPct` |
| 滞后降级阈值 | 0.3 × ATR | 突破/破位后已跑出这么远，信号降级为「等回踩/等反抽」 | 代码内固定 `0.3` |
| ATR | 日线 ATR14，逐品种写在剧本里 | 换算成价位的波动尺子 | `playbook.json` → `atr` |
| K 线周期 | 默认 1 分钟（可切 5 分钟 / 日线） | 「连续 3 根」数的是什么周期 | 页面顶部周期按钮 |

⚠️ **周期是活的**：切到 5 分钟后，「连续 3 根」= 15 分钟站稳，敏感度显著下降；切日线则几乎不出信号。悬停说明里会写明当前用的周期。

计算口径（不写死，可核对）：

- 收盘价序列 = 当前周期 K 线收盘价，最近一根可能是未走完的实时 K。
- `streak(cond)` = 从最后一根往前数，连续满足 `cond` 的根数。
- `0.3 × ATR` 用整数点表示，例如鸡蛋 ATR 87 → 26 点。

## 2. 方向倾向标签：「强多 / 偏多 / 中性 / 偏空 / 强空」

**全部由盘面数据实时算出来**（`dynDir()`），每 tick 重算，没有人工设定的成分。
历史上这里显示的是人工写的「剧本：做空」，2026-10-21 起已废弃删除 `playbook.json` 的 `direction` 字段。

| 打分项 | 取值 | 说明 |
|---|---|---|
| MA5 vs MA20 排列 | ±1.5 | MA5 > MA20 = 多头排列 +1.5，反之 −1.5 |
| 20 日区间位置 | ±0.5 | 现价在区间上沿 40% 内 +0.5，下沿 40% 内 −0.5，中间不计 |
| 四象限（持仓×价格） | +2 ~ −2 | 多头进攻 +2、空头回补 +1、无量整理 0、多头离场 −1、空头进攻 −2 |
| 资金失衡 | ±1 | 净流入占总额 ≥5% 才计，方向按多空 |

| 标签 | 总分 | 颜色 | 怎么读 |
|---|---|---|---|
| 强多 | ≥ +4 | 红 | 结构、位置、资金三块都指多，回踩做多为主 |
| 偏多 | +2 ~ +4 | 红 | 偏多但不够强，别追高，等回踩 |
| 中性 | 0 ~ +2 | **淡红** | 结论中性、偏多倾向，观望/区间高抛低吸 |
| 中性 | 0 | 黄 | 多空证据互相抵消，观望/区间高抛低吸 |
| 中性 | −2 ~ 0 | **淡绿** | 结论中性、偏空倾向，观望/区间高抛低吸 |
| 偏空 | −4 ~ −2 | 绿 | 偏空但不够强，别追空，等反抽 |
| 强空 | ≤ −4 | 绿 | 三块都指空，反抽滞涨做空为主 |

三个要点：

1. **它是方向，不是信号。** 显示「强空」不等于现在能空，只能说这个品种目前偏空；能不能动手看信号标签。
2. **盘中会自己翻。** 均线、区间位置、四象限、资金任一变化都会重算总分，不需要人工改文件。
3. **它不再决定信号走哪一侧。** 做多、做空两套信号并行计算，谁触发亮谁（见 §3）。
4. **颜色按分数连续过渡。** 标签文字只有五档，颜色有五档以上：`中性 +1` 是淡红、`中性 0` 是黄、`中性 −1` 是淡绿。同一个「中性」里也能看出偏向哪边，但**颜色偏红不等于能开多**——动手门槛仍是信号触发。

## 3. 信号标签：11 种状态

判定顺序固定（代码里从上到下 return，先命中先返回）：

```
① 有连续满足条件的 K 线？
     ├─ 满足根数 ≥ 3 且未跑出 0.3×ATR → 🔴 触发
     ├─ 满足根数 < 3               → 确认中 n/3
     └─ 满足根数 ≥ 3 但已跑出 0.3×ATR → ⚪ 滞后降级（等回踩 / 等反抽）
② 没有连续满足 → 价格是否在某个「接近」区域？
     ├─ 距关键位 ≤ 1%   → 🟡 接近…
     └─ 在滞涨区区间内  → 🟡 滞涨区试空
③ 都不满足 → 观望
```

### 3.1 做空信号（跌破「空破位」那一路）

| 标签 | 触发条件 | 判定逻辑 / 为什么 | 下一步 |
|---|---|---|---|
| 🔴 空头破位触发 | 连续 ≥3 根 K 线收盘 < `shortBreakdown`，且现价 ≥ 破位位 − 0.3×ATR | 有效破位：跌得够确认、又没跌太远，追空还在合理赔率内 | 按剧本机位进场，止损挂回破位位上方；重新站回即假破位，撤 |
| 破位确认中 n/3 | 收盘已跌破，但连续根数 < 3 | 单根跌破可能只是插针，等持续在下方才确认 | 等满 3 根不收回，或等反抽破位位滞涨 |
| ⚪ 已破位·等反抽 | 连续 ≥3 根成立，但现价 < 破位位 − 0.3×ATR | 破位已发生且跌远了，此处追空 = 卖在低位，赔率差 → **降级** | 不追空；等反抽到破位位附近滞涨（冲高回落/长上影）再试；反抽站回破位位上方则剧本作废 |
| 🟡 滞涨区试空 | 现价 ∈ `shortFadeZone` = [下限, 上限] | 破位前的最后一道压力带，空头性价比最高的位置 | 等滞涨信号轻仓试空，止损放区间上沿之上；放量突破上沿则暂停 |
| 🟡 接近破位 | 现价与破位位距离 ≤ 1%，且尚未跌破 | 提前预警，还没到动手的时候 | 盯破位位下方：连续 3 根收盘跌破且放量才追，缩量假摔不追 |
| 观望 | 未跌破破位位，也不在滞涨区 | 既没破位，也没到空头好位置 | 等反抽到滞涨区，或等真的跌破 |

### 3.2 做多信号（站上「多突破位」那一路）

| 标签 | 触发条件 | 判定逻辑 / 为什么 | 下一步 |
|---|---|---|---|
| 🔴 多头突破触发 | 连续 ≥3 根 K 线收盘 > `longTriggerBreak`，且现价 ≤ 突破位 + 0.3×ATR | 有效突破：站得住、又没追高 | 按剧本机位进场，止损同步挂上；跌回突破位下方 = 假突破，撤 |
| 突破确认中 n/3 | 收盘已站上，但连续根数 < 3 | 站上不等于站稳，防插针 | 等满 3 根不跌回，或等回踩突破位企稳 |
| ⚪ 已突破·等回踩 | 连续 ≥3 根成立，但现价 > 突破位 + 0.3×ATR | 突破已跑远，追多 = 买在高位 → **降级** | 不追多；等回踩突破位不破 + 收阳再进 |
| 🟡 接近突破位 | 距 `longTriggerBreak` ≤ 1% | 提前预警 | 盯放量站上，连续 3 根不回落才算触发 |
| 🟡 接近回踩位 | 距 `longPullback` ≤ 1% | 第二机位：回踩做多 | 在回踩位企稳（不创新低 + 收阳）轻仓试多；实体跌破则等下一档支撑 |
| 观望 | 未站上突破位，也不在两个机位的 1% 邻域内 | 中间地带没有参照物，不动手 | 等价格走到回踩位或突破位 |

### 3.3 边界情况

| 情况 | 表现 | 原因 |
|---|---|---|
| 关键位没配 | 「观望」，detail 写「多头/空头剧本未配置关键位」 | `levels` 缺 `longTriggerBreak` / `shortBreakdown` / `shortFadeZone`；跑一次 `levels.py` 会自动补齐 |
| 两边信号同时亮 | 头部同时显示「多 …触发」和「空 …触发」 | 极罕见（如日内剧烈反转后 K 线序列混杂）；以方向倾向总分为准，两边都不做 |
| 方向中性但信号触发 | 信号照常显示，方向标签维持「中性」 | 信号只看价格与关键位，方向是综合分，两者本来就可以不一致 |
| K 线未就绪 | 「--」 | 刚开进程、K 线还在拉，等几秒 |

## 4. 持仓状态标签：4 档 + 固定优先级

判定顺序即优先级（**先判止损，再判趋势目标，最后判波段目标**）：

```
① 触止损（剧本失效）        → 短线止损已破 ⚠️
② 到趋势目标（更远那个）    → 趋势目标到达 ✓
③ 到波段目标（较近那个）    → 波段目标到达 ✓
④ 都没到                   → 持有区间内
```

| 标签 | 判定条件（空单 / 多单） | 为什么这么排 | 下一步 |
|---|---|---|---|
| 短线止损已破 ⚠️ | 空单：价 ≥ `stop`；多单：价 ≤ `stop` | 止损是剧本的前提，破了后面全部作废，必须第一个判 | 先离场，不补仓、不等回本；要再进必须等新信号 |
| 趋势目标到达 ✓ | 空单：价 ≤ `trendTarget`；多单：价 ≥ `trendTarget` | 趋势目标比波段目标远，**必须先判**，否则冲过趋势目标时会被误标成「波段目标到达」 | 剩余仓位改移动止损跟随，别在这里反手 |
| 波段目标到达 ✓ | 空单：价 ≤ `waveTarget`；多单：价 ≥ `waveTarget` | 到了第一目标但还没走完 | 先减一半落袋，余仓跟到趋势目标 |
| 持有区间内 | 价夹在 `stop` 与 `waveTarget` 之间 | 没破止损、也没到任何目标——没有动作可做，只有持有 | 破止损离场，到波段目标减半，趋势目标再看 |

举例（鸡蛋 jd2612，2026-10-21 盘中实测）：空单，短线止损 3318 / 波段止损 3626 / 波段目标 3082 / 趋势目标 2988，现价 3263。
3263 < 3318（没破短线止损）、未到 3082（没到波段目标）→ **持有区间内**。

### 4.1 持仓建议的方向词：7 个词（含「待验」降级）

持仓建议块标题后面那个词（如「持仓建议 · 持空待验」），由 `advDir()` 算，只回答一件事：**手上这笔单，现在该用什么姿势拿。**

| 词 | 判定（以空头排列表述，多头为镜像） | 操作含义 |
|---|---|---|
| **顺势持空** | 现价 < MA5，且当日资金没有反向 | 结构顺，可以持；破 MA5 减，破 MA20 全走 |
| **持空待验** | 现价 < MA5，**但当日资金反向** | 只减不加，守 MA5；结构没判输，但别按顺势行情拿 |
| **止跌观望** | 现价 ≥ MA5 | 短线动能已反，别追空；等站稳再谈多 |
| **区间高抛低吸** | 均线缠绕（`bias = range`） | 上下沿来回做，突破区间再换模式 |
| **回调观望 / 顺势持多** | 多头排列的镜像逻辑 | 跌破 MA5 = 别追多；仍在 MA5 上 = 可持多 |

**判定顺序（先看排列，再看价格，最后看资金）：**

```
① 日线排列是震荡（bias = range）？ → 区间高抛低吸，往下不看
② 空头排列：现价 ≥ MA5 → 止跌观望
             现价 < MA5 → 资金反向？ 是 → 持空待验   否 → 顺势持空
③ 多头排列：现价 ≤ MA5 → 回调观望
             现价 > MA5 → 资金反向？ 是 → 持多待验   否 → 顺势持多
```

**「资金反向」的触发线（`fundAgainst()`，三个条件同时满足）：**

| 条件 | 空单 | 多单 |
|---|---|---|
| 四象限方向逆着持仓 | 多头进攻 或 空头回补（价格在上） | 空头进攻 或 多头离场（价格在下） |
| 强度达标 | 净流入占成交额 **≥15%**（`net_ratio`） | 净流出占成交额 **≥15%** |
| 价格未破位 | 现价仍在 MA5 下方 | 现价仍在 MA5 上方 |

命中时，卡片底部会有一行黄字写明具体数值，例如：
「资金反向：今日价格上行、资金净流入 28.3%（增仓上涨·多头进攻）」。

**与「方向倾向」的区别（最容易混的一处）：**

| | 持仓方向词 | 方向倾向（头部徽章） |
|---|---|---|
| 回答 | 手上这笔单怎么拿 | 盘面偏哪边 |
| 算法 | 只看「现价 vs MA5」+ 当日资金是否反向 | 四项打分：均线排列 ±1.5 / 区间 ±0.5 / 四象限 ±2 / 资金失衡 ±1 |
| 阈值 | 无总分 | ≥2 才算偏多（≥4 强多） |
| 允许冲突 | 可以同时出现「持空待验」+「中性 +1」，这是正常的 | —— |

**「待验」≠「偏多」**：方向倾向到 +2 才叫偏多；「持空待验」只表示空单遇阻，离偏多还隔着一个「止跌观望」。方向词的强弱梯度：

```
顺势持空  >  持空待验  >  止跌观望  >  回调观望  >  顺势持多
（空头最顺）（空头遇阻）（僵持/多头初占优）（多头遇阻）（多头最顺）
```

实测（鸡蛋 jd2612，2026-10-21 上午）：现价 3263 < MA5 3318（结构没破）+ 增仓上涨 4.54% + 净流入 28.3%（资金反向）→ **持空待验**；同一时刻头部方向倾向是「中性 +1」，两处并不矛盾。若午后收盘站上 3318，方向词切「止跌观望」，与「短线止损已破」同一时点成立。

### 4.2 「我的仓位」开关：手上拿的是反向单怎么办

上面的方向词默认**按盘面趋势给**——空头排列就说「顺势持空」，它不关心你手上实际拿的是哪边。如果你持的是反向单（比如空头排列里拿着多单），老页面不会提醒你，这是缺口。

现在持仓建议块标题右侧有一组切换器：**空单 / 多单 / 空仓 / 顺趋势**（每品种独立，存浏览器本地；`顺趋势` 就是原来的「默认」）。

| 选择 | 页面行为 |
|---|---|
| **顺趋势**（不声明仓位，默认值） | 和以前一样：按盘面 bias 给顺势档位。此时方向词里的「持空 / 持多」指的是**顺趋势的那一边**，不代表你实际拿的单子——持反向单的人必须切到对应项，否则看到的建议与自己的仓位不匹配 |
| 空单 + 盘面空头（或 多单 + 盘面多头） | 顺势：还是那套档位，只是明确告诉你「这套是给你这边的」 |
| **多单 + 盘面空头**（或 空单 + 盘面多头） | **逆势**：换用 `advice.counter` 那套档位——止损放反方向、目标看回均线，方向词显示「逆势持多 / 逆势持空」 |
| 空仓 | 不显示持仓建议，改显机位（开仓参考 / 止损 / 波段目标 / 趋势目标） |

**逆势档位怎么定**（bias=bear、手上多单为例；空头空单完全镜像）：

| 档位 | 取值 | 逻辑 |
|---|---|---|
| 短线止损 | 20日低 + 0.3×ATR（鸡蛋 3204） | 跌到这里说明反弹失败，先减 |
| 波段止损 | 20日低（鸡蛋 3176） | 破前低 = 反弹彻底结束，逆势单全走，**不摊平** |
| 波段目标 | MA5（鸡蛋 3318） | 反弹到 MA5 不过就减——逆势单的第一目标不是趋势低点 |
| 趋势目标 | MA20（鸡蛋 3626） | 站上 MA20 才算转势，那之后这套档位作废、按顺势多头重新看 |

逆势持仓的核心提醒只有一句话：**止损放反方向、不摊平、目标看回均线，反弹到位就减。** 方向词的「待验/资金反向」逻辑（§4.1）对逆势单同样适用，但逆势单的默认姿态就是「只减不加」，无需等资金反向。

## 5. 关键位阶梯上的状态标记：「最近 / 已破 / 已上破」

两套阶梯同名不同值，别混：

| 阶梯 | 算法 | 重算时机 | 管什么 | near 阈值 |
|---|---|---|---|---|
| 波段位 | 日线 20 日高低 + ATR + MA | 收盘后 | 这周在哪做 | 1.5% |
| 日内位 | 昨结算 ± ATR | 盘中实时 | 今天在哪接、在哪压 | 0.8% |

| 标记 | 判定 | 含义 |
|---|---|---|
| 最近 | 只在「尚未被破」的档里挑与现价距离最小的一档，且距离 ≤ 阈值 | 当前多空就在这条线上博弈 |
| 已破 / 已上破 | 支撑：现价 < 该位；压力：现价 > 该位 | 支撑失效会变压力，压力被上破会变回踩支撑 |
| 距现价 X% | (该位 ÷ 现价 − 1) × 100，正数=该位在现价上方 | 红色加粗 = 距离 ≤ 0.8%，贴脸了 |

## 6. 资金类标签

### 6.1 四象限：「多头进攻·强多 / 空头回补·弱多 / 空头进攻·强空 / 多头离场·弱空 / 无量整理·观望」

两轴：**当日涨跌（相对昨结算）** × **持仓变化率**，任一轴不足 1% 归入无量整理。

| 标签 | 条件 | 含义 |
|---|---|---|
| 多头进攻 · 强多 | 价涨 + 增仓 ≥1% | 新钱进场做多，趋势最可信 |
| 空头回补 · 弱多 | 价涨 + 减仓 ≥1% | 空头止损推上去的，燃料会烧完 |
| 空头进攻 · 强空 | 价跌 + 增仓 ≥1% | 新钱进场做空，趋势最可信 |
| 多头离场 · 弱空 | 价跌 + 减仓 ≥1% | 多头获利了结，跌势可能衰竭 |
| 无量整理 · 观望 | 任一轴不足 1% | 方向不明 |

### 6.1b 「多空力量」多/空占比（与参考站同口径）

占比**不是逐笔统计**，是四象限定性结论的量化：

```
基准 D：多头进攻 100 / 空头进攻 0 / 空头回补 35 / 多头离场 65 / 无量整理 50
强度 X = min(|持仓变化率| ÷ 3, 1)
多头占比 = 50 + (D − 50) × (0.5 + 0.5 × X)
新增头寸 = ΔOI × 现价 × 乘数（亿）；多/空金额 = |新增头寸| 按占比拆分
「多头/空头净流入」= 两者中较大的一侧
```

变化率 ≥3% 时占比完全取基准值，越小越向 50% 收敛——所以强四象限下常见 95%+ 的极端值。

注意两点：

1. 它与下方小字「实测手数 多/空%」是**两套口径**：这条看"四象限结论的分布"，
   实测那条看"逐分钟 ΔOI 归属统计"；减仓日两者会明显背离，并存互相印证。
2. 乘数本页用「元/点」，参考站此块用「合约单位」：四个品种相同，仅鸡蛋不同
   （合约 5 吨 vs 1 点 10 元），鸡蛋金额本页是参考站的 2 倍。

### 6.2 其他资金标签

| 标签 | 口径 |
|---|---|
| 多头净流入 / 空头净流入 | 多头侧成交额 − 空头侧成交额（按分钟收盘方向归属），**不是逐笔主动成交** |
| 持仓动作 多 X% / 空 Y% | 按「价格方向 × 持仓增减」把每分钟 ΔOI 归到动作方（手数口径），涨+增仓/跌+减仓计多方，跌+增仓/涨+减仓计空方 |
| 低换手·参考性较好 / 换手偏高·谨慎看 / 高频换手·估算失真大 | 成交额 ÷ 持仓市值 < 0.5 / 0.5~1.2 / ≥1.2 |
| 资金反向（触发「持X待验」） | 四象限逆着持仓方向 **且** 净流入/流出占成交额 ≥15% **且** 价格仍在 MA5 顺侧；三条同时成立才降级方向词（见 §4.1） |

## 7. 四个最常见的误读

1. **把方向当信号。** 「强空」不代表现在能空。能不能空看信号标签，位置安不安全看持仓标签。
2. **把「接近」当「触发」。** 🟡 是预警（还差最后一步），🔴 才是条件已满足；⚪ 是「条件满足但已经错过最佳赔率」。
3. **把资金估算当真实成交。** 净流入是分钟 K 线收盘方向 × 成交额的近似，高频换手时失真明显；四象限（持仓×价格）比它可信，两个口径不能互相替代。
4. **把「持空待验」当「偏多」。** 「待验」只说明空头遇阻、资金逆风，操作上是「只减不加」，不是反手做多的信号。真转多要看到：站上 MA5 → 方向词切「止跌观望」→ 方向倾向升到 +2 偏多，三步走完才算（见 §4.1）。

### 8.2 浮层闪烁修复（2026-10-20 16:20）

症状：资金块右侧标签（四象限「多头离场 · 弱空」、净流入数值）悬停时浮层一直闪。

根因两层：

1. 资金块 `renderFlow()` 每 tick 整块 `innerHTML` 重绘，悬停中的标签节点被连根换掉 → 浮层 hide；
   浏览器对新节点补发 mouseover → 130ms 后再 show → 下一个 tick 又 hide → 周期性闪烁
2. 旧实现每 200ms 同步都重写浮层 DOM，即使内容一字未变

修复（`#wbtip` IIFE + `renderFlow`）：

- `sync()/hide()` 检测到旧节点已脱离文档时，按光标坐标 `elementFromPoint` **接管新节点**继续显示，不再隐藏
- `hide()` 延迟 120ms 执行（可被新悬停取消），防快速过境闪烁
- 浮层文本加缓存（`lastText`），内容没变不重写 DOM
- `renderFlow()` 整段 HTML 加缓存（`_flowCache`），内容没变不动 DOM，从源头减少节点重建

实测：模拟 28 次连续重绘，三处悬停点（四象限标签/净流入数值/多空力量条）浮层全程稳定（0 次隐藏）；
离开隐藏、跨标签切换内容均正常。

## 10. 名词对照表（看不懂的术语先查这里）

页面上的术语分三类：**价位类**（多突破位、空破位…）、**资金类**（四象限、净流入…）、**指标类**（ATR、分位…）。
每条都给一句「见到它该怎么用」，不做教科书式定义。

### 10.1 价位类：这些价是拿来干嘛的

| 术语 | 代码字段 | 一句话解释 | 怎么用 |
|---|---|---|---|
| **多突破位** | `longTriggerBreak` | 价格站到它上方，才算多头真的起来了 | 站上并连续 3 根站稳 → 顺势做多；站上去又掉下来 = 假突破，不做 |
| **多回踩位** | `longPullback` | 涨上去后回落到的那个支撑价 | 回踩到这儿不破、重新收阳 → 比追高更划算的进场点 |
| **空破位** | `shortBreakdown` | 价格跌破它，才算空头成立 | 跌破并连续 3 根站不回来 → 顺势做空；又收回去 = 假破位，撤 |
| **滞涨区** | `shortFadeZone` | 反弹到这一带涨不动的价格区间 | 冲高回落 / 长上影 / 1 分钟转阴 → 轻仓试空，止损放区间上沿 |
| **压力位 / 前高** | `resistance` | 20 日内的最高价 | 涨到这附近容易遇到卖压 |
| **第一支撑** | `firstSupport` | 跌破后第一道可能撑住的价 | 短线止盈/减仓的参考 |
| **强撑** | `strongSupport` | 20 日内的最低价（真实前低） | 破了它通常意味着趋势要变 |
| **失守目标** | `stopTarget` | 强撑再往下的一段（强撑 − 0.5 ATR） | 真跌到这儿，原多头逻辑彻底作废 |
| **短线止损** | `advice.shortStop` | 短线动能证伪线（空头=MA5，多头=MA5） | 破了先平短线仓/加仓部分，底仓可留 |
| **波段止损** | `advice.swingStop` | 趋势生命线（MA20 或震荡区间外沿） | 破了整笔离场，不补仓、不等回本 |
| **波段目标** | `advice.swingTarget` | 第一段行情大概能到的价 | 到了先减一半落袋，余仓改移动止损 |
| **趋势目标** | `advice.trendTarget` | 趋势走顺了才看的位置 | 只在趋势里用，震荡不给 |
| **机位** | `plan.entry` | 还没进场时的开仓计划 | 和「持仓建议」分开看：机位管怎么进，建议管进了怎么拿 |
| **剧本 / playbook** | `playbook.json` | 每个品种的「作战底稿」：关键位、机位、产业信号、季节参数 | 数据和规则放文件里，代码只管算；跑 `levels.py` 会刷新其中的价位 |

### 10.2 状态类：标签说的到底是哪种状态

| 术语 | 含义 | 见到它意味着 |
|---|---|---|
| **多突破触发 / 空破位触发** | 收盘连续 N 根站上/跌破关键位 | 条件成立，可按机位进场 |
| **确认中 1/3** | 才连续 1 根满足，门槛是 3 根 | 可能是插针，先不动手 |
| **已突破·等回踩 / 已破位·等反抽** | 突破/破位成立，但价格已跑出 0.3 ATR 以上 | 追进去赔率差，等回踩/反抽再进 |
| **接近突破位 / 接近破位** | 距关键位不足 1% | 盯盘，等触发，不是现在就做 |
| **持有区间内** | 没破止损、也没到目标 | 拿着，什么都不用做 |
| **短线止损已破** | 现价越过短线止损 | 短线仓该走；波段仓看下一道波段止损 |
| **波段止损已破** | 现价越过波段止损 | 整笔离场，剧本作废 |
| **止跌观望 / 顺势持空** | 空头排列里，现价是否已站上 MA5 | 站上 MA5 = 短线动能没了，别追空；仍在下方 = 还能持空 |
| **逆势持多 / 逆势持空** | 在「我的仓位」里声明了与盘面相反的方向（§4.2） | 这套档位是给逆势单的：止损放反方向（20日低/高）、目标看回 MA5→MA20；核心是「不摊平、反弹到位就减」 |
| **持空待验 / 持多待验** | 日线结构没破（价格仍在 MA5 顺侧），但**当天资金在往反方向走**（四象限逆着持仓方向 + 净流入/流出占比 ≥15%） | 「顺势」二字被摘掉：只减不加、守 MA5；结构没判输，但当天别按顺势行情做。悬停和卡片底部黄字会写资金反向的具体数值。**它不是偏多**——详见 §4.1 |
| **回调观望 / 顺势持多** | 多头排列的镜像逻辑 | 跌破 MA5 = 别再追多；仍在 MA5 上 = 可持多 |
| **区间高抛低吸** | 均线缠绕，没有趋势 | 靠近区间上沿卖、下沿买，突破区间再换模式 |

### 10.3 资金类

| 术语 | 含义 | 怎么读 |
|---|---|---|
| **四象限** | 相对昨结算的「价格涨跌 × 持仓增减」四种组合 | 涨价+增仓=多头进攻（最强）；跌价+增仓=空头进攻（最弱）；涨价+减仓=空头回补（弱多）；跌价+减仓=多头离场（弱空） |
| **净流入（多−空）** | 当日分钟序列里主动买 − 主动卖的估算金额 | 正=买盘主动，负=卖盘主动；这是**估算**不是交易所数据 |
| **多空额比** | 主动买金额 / 主动卖金额 | 多 63 / 空 37 = 买盘占优 |
| **失衡度** | 净流入占总额的百分比 | 绝对值 ≥5% 才计入方向打分，太小视为噪音 |
| **持仓变化** | 相对昨结算的总持仓增减 | 增仓=有新钱进来，减仓=有人离场；配合价格看方向 |
| **量比** | 当日成交量 / 近 5 日同时段均量 | >1 放量，<1 缩量 |

### 10.4 指标类

| 术语 | 含义 | 怎么用 |
|---|---|---|
| **ATR14** | 近 14 天日均真实波幅（当天最高−最低、含跳空的平均） | 全站的「波动尺子」：止损距离、突破滞后阈值 0.3 ATR、基差深浅都按它算 |
| **MA5 / MA20** | 5 日 / 20 日收盘均线 | MA5 = 短线动能线，MA20 = 波段趋势线 |
| **历史分位** | 现价在近 5 年日线收盘中的百分位 | ≤20% = 历史低位，≥80% = 历史高位；分位低不等于会涨，只说明位置便宜 |
| **基差** | 现货价 − 期货价（**计算时**先把现货折算到期货报价单位再相减；页面上的现货价仍显示原始报价） | 正值=现货升水/盘面贴水，下方有现货买盘托底；负值=现货贴水/盘面升水，上方有套保压力 |
| **基差 ×ATR** | 基差 ÷ ATR | 跨品种比「贴水深不深」：<0.3 平水 / <1 小幅 / <2 明显 / ≥2 深 |
| **BOLL** | 布林带（20 日均线 ±2 倍标准差） | 中轨=MA20 性质的支撑压力，上下轨=极端位置 |
| **MACD** | 12/26 日 EMA 之差与 9 日信号线 | 只作辅助，不单独出信号 |
| **KDJ / RSI** | 超买超卖震荡指标 | 同上，辅助判断是否过热 |
| **季节性** | 同品种各月的历史涨跌均值与胜率 | 判断「这个月历史上偏强还是偏弱」，不构成单月方向 |

### 10.5 数据口径提醒

| 说法 | 意思 |
|---|---|
| **收盘口径** | 盘中无报价时（15:00–21:00）基差、关键位用日线最后一根收盘价算，不是实时价 |
| **积累中 2/3 天** | 基差历史分位要攒够 3 个交易日才显示，不足时不瞎给结论 |
| **数据滞后** | 现货源超过 6 小时没更新，基差仅供参考 |
| **估算（资金流向）** | 用分钟 K 线的买卖方向反推，不是交易所逐笔数据，只能看倾向不能当精确值 |
